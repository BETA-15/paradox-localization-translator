Paradox の歴史ストラテジーの Mod に

Mod を、あなたの言語へ。ローカル LLM でも、クラウドの AI でも。

Mod を作る人・遊ぶ人のための無料のデスクトップ用ツールです。Crusader Kings III、Victoria 3、Hearts of Iron IV、Stellaris、Europa Universalis IV・V の Mod のローカライズを、ゲームが対応する11言語のどれへでも翻訳します。ゲームの書式の記号は壊さず、訳し残しも見つけて直せます。

できること

01

Mod をまとめて翻訳

ファイル1つ、localisation フォルダ、Mod まるごと、どれでも追加できます（ドラッグ＆ドロップも可）。複数の Mod を順番に処理でき、一時停止・再開や、中断して次回に続きから始めることもできます。

02

ゲームの記号を壊さない

[ROOT.Char.GetName]、$VALUE$、£gold£、§Y…§! などの書式の記号を、翻訳の間は保護して最後に元へ戻します。ゲームの表示が崩れません。

03

訳すだけでなく、直す・更新する

訳し残しの行を見つけて、その行だけ訳し直します。Mod が更新されたら、増えた行・変わった行だけを訳します。キャッシュは翻訳ごとに別に持ちます。

04

既存の翻訳 Mod を見つける

ある Mod を、別の Mod がすでにあなたの言語へ翻訳しているか、その翻訳に欠けがないかを調べます。欠けている行は、元の Mod ではなく翻訳 Mod のほうへ足せます（先にバックアップを取り、確認してから）。

05

確かめて、仕上げる

原文と訳文を並べて比べ、品質チェックをかけ、どの行でも検索して直接直せます。用語集を作れば、人名や用語の訳がそろいます。

06

AI は選べる

Ollama や LM Studio のローカルのモデル（無料・手元で完結）でも、OpenAI・Anthropic・Google Gemini・OpenAI 互換の API でも使えます。API キーは設定・プロファイル・ログに保存しません。

使い方

  1. AI を用意する

    Ollama か LM Studio を起動してモデルを読み込みます。クラウドを使うなら API キーを用意します。

  2. ダウンロードして起動する

    最新版から、お使いの OS 用のファイルを選びます。

  3. モデルを選ぶ

    「モデル / 接続」で、使うサービスとモデルを選びます。

  4. Mod を追加して翻訳する

    ファイル・フォルダ・Mod を追加し（ドラッグ＆ドロップ可）、翻訳先の言語を選んで「翻訳開始」を押します。

  5. 確かめてから反映する

    「QA / 比較編集」で確かめてから、完成した訳を Mod へ書き込みます。書き込む前にバックアップを取ります。

必要なもの

ローカルで使う

Ollama か LM Studio と、翻訳先の言語を上手に書けるモデル（例：Qwen 系、Gemma 系）。

クラウドで使う

OpenAI・Anthropic・Google Gemini・OpenAI 互換サービスの API キー。料金はそのサービスから請求されます（このツールの料金ではありません）。

翻訳した Mod を公開するときのお願い

このツールで作った翻訳を Steam Workshop などで公開するときは、次をお願いします。

  • 元の Mod の作者の許可を取ってください。 Mod の世界の慣習で、Steam の利用規約でも、投稿者は投稿する内容の権利を持っている必要があります。
  • 無料で公開してください。 Paradox Interactive の利用規約（User Agreement 第5条）では、Mod などのユーザー作成コンテンツは誰でも無料で使えるようにする必要があり、有料の壁の向こうには置けません。かけた時間への寄付を受けることは認められています。
  • 機械翻訳なら、その旨を書いてください。 遊ぶ人が判断しやすくなります。

よくある質問

本当に無料ですか？

はい。すべての機能を誰でも無料で使えます（MIT ライセンス）。有料版はありません。

macOS で「開けません」と出る。

Apple の署名がないためです。システム設定の「プライバシーとセキュリティ」から起動を許可してください。

Windows で SmartScreen の警告が出る。

コード署名をしていないためです。公式の GitHub Releases からだけダウンロードし、「詳細情報」→「実行」を選んでください。

Steam Workshop の Mod を直接翻訳できますか？

できます。ただし Workshop の更新で変更が消えることがあります。ツールはバックアップを取りますが、大事な翻訳は控えも残してください。

不具合はどこに報告すればいいですか？

GitHub の Issues へお願いします。できれば、設定 →「診断ログを収集」で作った診断 ZIP と、起きたときの操作の手順を添えてください。診断 ZIP に訳文や API キーは入りません。
