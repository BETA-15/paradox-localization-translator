Paradox 대전략 게임 모드용

로컬 LLM이나 클라우드 AI로 모드를 원하는 언어로 번역합니다.

모드 제작자와 플레이어를 위한 무료 데스크톱 도구입니다. Crusader Kings III, Victoria 3, Hearts of Iron IV, Stellaris, Europa Universalis IV 및 V, Imperator: Rome의 모드 현지화 파일을 게임에서 지원하는 11개 언어 중 원하는 언어로 번역합니다. 게임 서식 코드를 그대로 유지하며, 아직 번역되지 않은 부분을 찾아 수정할 수 있습니다.

주요 기능

01

모드 전체를 한 번에 번역

파일 하나, 현지화 폴더 또는 모드 전체를 추가하거나 끌어다 놓습니다. 여러 모드를 대기열에 넣고, 일시 정지하거나 재개할 수 있으며, 중지한 뒤 다음에 이어서 진행할 수도 있습니다.

02

게임 코드 보호

[ROOT.Char.GetName], $VALUE$, £gold£, §Y…§! 같은 서식 코드를 번역 중에 보호하고 번역 후 복원하여 게임 텍스트가 깨지지 않도록 합니다.

03

번역뿐 아니라 보완과 업데이트까지

번역되지 않은 줄을 찾아 해당 줄만 번역합니다. 작업마다 별도의 캐시를 유지합니다. 모드가 업데이트되면 이미 번역한 줄을 재사용하므로 새로 추가되거나 변경된 줄만 AI에 보냅니다.

04

기존 번역 모드 검색(일본어)

일본어의 경우, 해당 모드를 번역한 다른 모드가 있는지, 번역이 완전한지 확인합니다. 먼저 백업과 확인을 거친 뒤, 누락된 줄을 원본 모드 대신 번역 모드에 추가할 수 있습니다.

05

검토 및 다듬기

원문과 번역문을 나란히 비교하고, 품질 검사를 실행하며, 원하는 줄을 검색하여 바로 수정할 수 있습니다. 언어별 용어집으로 이름과 용어를 일관되게 유지합니다.

06

원하는 AI 선택

Ollama나 LM Studio로 로컬 모델을 무료로 실행하며 데이터를 비공개로 유지할 수 있습니다. 또는 OpenAI, Anthropic, Google Gemini 및 OpenAI 호환 API를 사용할 수 있습니다. API 키는 설정, 프로필, 로그에 저장되지 않습니다.

스크린샷

스크린샷에는 앱의 일본어 화면이 표시되어 있습니다. 한국어 화면도 제공할 예정입니다.

게임 및 언어

공식 지원 언어 11개 모두로 번역할 수 있습니다. 각 게임에서 읽을 수 있는 언어는 이 중 일부입니다. 게임이 표시할 수 없는 언어를 선택하면 시작 전에 경고합니다. Crusader Kings III, Victoria 3, Hearts of Iron IV, Stellaris, Europa Universalis V는 모드를 자동으로 감지합니다. Europa Universalis IV와 Imperator: Rome은 파일이나 폴더를 직접 추가해야 합니다.

사용 방법

  1. AI 준비

    Ollama나 LM Studio를 실행하고 모델을 불러오거나, 클라우드 서비스용 API 키를 준비합니다.

  2. 앱 다운로드 및 실행

    최신 릴리스에서 운영 체제에 맞는 파일을 선택합니다.

  3. 모델 선택

    "모델 / 연결"에서 제공업체와 모델을 선택합니다.

  4. 모드 추가 및 번역

    파일, 폴더 또는 모드를 추가하고(끌어다 놓기도 가능), 번역 대상 언어를 선택한 뒤 "번역 시작"을 누릅니다.

  5. 검토 후 적용

    "QA / 비교 편집"에서 결과를 검토한 뒤 완성된 번역을 모드에 씁니다. 먼저 백업을 만듭니다.

준비물

로컬

Ollama 또는 LM Studio와 번역 대상 언어를 잘 구사하는 모델(예: Qwen 또는 Gemma 모델)이 필요합니다.

클라우드

OpenAI, Anthropic, Google Gemini 또는 OpenAI 호환 서비스의 API 키가 필요합니다. 사용 요금은 이 도구가 아니라 해당 서비스에서 청구합니다.

번역 모드 배포

이 도구로 만든 번역을 Steam Workshop이나 다른 곳에 공유할 때는 다음 사항을 지켜 주세요.

  • 원본 모드 제작자의 허락을 받으세요. 이는 모드 커뮤니티의 관례이며, Steam 약관에서도 업로드하는 콘텐츠에 대한 권리를 보유하도록 요구합니다.
  • 무료로 배포하세요. Paradox Interactive의 사용자 계약(제5조)에 따라 모드와 기타 사용자 제작 콘텐츠는 누구나 무료로 이용할 수 있어야 하며, 결제해야만 이용할 수 있도록 해서는 안 됩니다. 작업에 들인 시간에 대한 기부는 받을 수 있습니다.
  • 기계 번역 여부를 밝혀 주세요. 기계 번역을 사용했다면 이를 표시하면 플레이어가 판단하는 데 도움이 됩니다.

자주 묻는 질문

정말 무료인가요?

네. MIT 라이선스에 따라 모든 기능이 누구에게나 무료입니다. 유료 버전은 없습니다.

모든 언어에서 모든 기능을 사용할 수 있나요?

번역, 미번역 줄 보완, QA, 검색, 용어집은 11개 언어 모두에서 사용할 수 있습니다. 모드 조사, 번역 모드 감지 및 연결, 업데이트 부분만 번역, 중국어 기반 번역, 용어집 자동 생성은 현재 일본어에서만 사용할 수 있습니다. 다른 언어의 품질 검사는 더 단순합니다. 한국어, 러시아어, 중국어 간체는 문자 체계를 기준으로 검사하며, 라틴 문자 언어 간에는 원문과 동일한 줄만 표시합니다.

macOS에서 앱을 열 수 없다고 합니다.

이 앱에는 Apple 서명이 없습니다. 시스템 설정 → 개인정보 보호 및 보안에서 실행을 허용합니다.

Windows에 SmartScreen 경고가 표시됩니다.

이 앱에는 코드 서명이 없습니다. 공식 GitHub Releases 페이지에서만 다운로드한 뒤 "추가 정보" → "실행"을 선택합니다.

Steam Workshop 모드를 직접 번역할 수 있나요?

네. 다만 Workshop 업데이트로 변경 내용이 덮어써질 수 있습니다. 도구에서 백업을 만들지만, 중요한 번역은 별도로 사본을 보관하세요.

버그는 어떻게 신고하나요?

GitHub에 이슈를 등록합니다. 가능하면 "설정" → "진단 로그 수집"에서 만든 진단 ZIP을 첨부하고 재현 절차를 설명해 주세요. ZIP에는 번역문이나 API 키가 포함되지 않습니다.

Paradox Localization Translator는 개인 개발자가 만든 비공식 도구입니다. Paradox Interactive와 제휴 관계가 없으며, 해당 회사의 보증을 받지 않았습니다. Paradox Interactive, Crusader Kings, Victoria, Hearts of Iron, Stellaris, Europa Universalis는 각 소유자의 상표입니다.
