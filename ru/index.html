Для модов глобальных стратегий Paradox

Переводите моды на свой язык с помощью локальной LLM или облачного ИИ.

Бесплатное настольное приложение для авторов модов и игроков. Оно переводит файлы локализации модов для Crusader Kings III, Victoria 3, Hearts of Iron IV, Stellaris, Europa Universalis IV и V, а также Imperator: Rome на любой из 11 поддерживаемых играми языков, сохраняет коды форматирования игры и помогает найти и исправить непереведённый текст.

Возможности

01

Перевод модов целиком

Добавьте отдельный файл, папку локализации или целый мод — в том числе перетаскиванием. Поставьте несколько модов в очередь; приостанавливайте и возобновляйте работу или остановите её и продолжите в следующий раз.

02

Защита кодов игры

Коды форматирования, такие как [ROOT.Char.GetName], $VALUE$, £gold£ и §Y…§!, защищаются на время перевода и восстанавливаются после него, чтобы текст в игре отображался правильно.

03

Дополнение и обновление перевода

Находит непереведённые строки и переводит только их. У каждой задачи свой кэш: при обновлении мода готовые переводы используются повторно, поэтому ИИ получает только новые или изменённые строки.

04

Поиск готовых переводов на японский

Для японского языка инструмент проверяет, есть ли другой мод с переводом этого мода и полностью ли он переведён. Недостающие строки можно добавить в мод перевода вместо исходного мода — после создания резервной копии и подтверждения.

05

Проверка и правка

Сравнивайте оригинал и перевод рядом, запускайте проверку качества, находите и исправляйте любые строки прямо в приложении. Ведите глоссарий для каждого языка, чтобы имена и термины были единообразными.

06

ИИ на ваш выбор

Запускайте локальную модель через Ollama или LM Studio — бесплатно и конфиденциально — либо используйте OpenAI, Anthropic, Google Gemini или любой API, совместимый с OpenAI. Ключи API никогда не сохраняются в настройках, профилях или журналах.

Скриншоты

На скриншотах показан японский интерфейс приложения; планируется интерфейс на русском языке.

Игры и языки

Инструмент может переводить на все 11 официальных языков. Каждая игра читает лишь часть из них; если выбрать язык, который игра не может отображать, инструмент предупредит об этом до начала работы. Автоматическое обнаружение модов поддерживается для Crusader Kings III, Victoria 3, Hearts of Iron IV, Stellaris и Europa Universalis V; для Europa Universalis IV и Imperator: Rome файлы или папки нужно добавить вручную.

Как пользоваться

  1. Подготовьте ИИ

    Запустите Ollama или LM Studio и загрузите модель либо подготовьте ключ API облачного сервиса.

  2. Скачайте и откройте приложение

    Выберите файл для своей системы в последнем выпуске.

  3. Выберите модель

    В разделе «Модели» выберите провайдера и модель.

  4. Добавьте мод и переведите

    Добавьте файл, папку или мод (можно перетащить), выберите язык перевода и нажмите «Начать перевод».

  5. Проверьте и примените

    Проверьте результат в разделе «QA / Сравнение», затем запишите готовый перевод в мод. Сначала будет создана резервная копия.

Что понадобится

Локально

Ollama или LM Studio и модель, которая хорошо пишет на нужном языке (например, модели Qwen или Gemma).

В облаке

Ключ API для OpenAI, Anthropic, Google Gemini или сервиса, совместимого с OpenAI. Плату за использование взимает сам сервис, а не этот инструмент.

Публикация переведённого мода

Если вы делитесь переводом, сделанным с помощью этого инструмента, в Steam Workshop или где-либо ещё, пожалуйста:

  • Получите разрешение автора исходного мода. Так принято в сообществе авторов модов, а условия Steam требуют, чтобы у вас были права на загружаемый контент.
  • Публикуйте бесплатно. Пользовательское соглашение Paradox Interactive (раздел 5) требует, чтобы моды и другой пользовательский контент были бесплатны для всех; доступ к ним нельзя ограничивать платой. Принимать пожертвования за потраченное время разрешено.
  • Укажите, что перевод машинный, если это так. Это поможет игрокам сделать выбор.

Поддержать разработку

Пожертвования поступают через GitHub Sponsors в VF Software Co., Ltd. Они помогают покрывать время и затраты на разработку всех наших проектов, включая этот инструмент. Все функции остаются бесплатными для всех, а пожертвования ничего не открывают.

Вопросы и ответы

Это действительно бесплатно?

Да. Все функции бесплатны для всех и доступны по лицензии MIT. Платной версии нет.

Все ли функции работают со всеми языками?

Перевод, дополнение непереведённых строк, QA, поиск и глоссарии работают для всех 11 языков. Обзор модов, обнаружение и привязка модов перевода, перевод только обновлений, перевод на основе китайского текста и автоматическое создание глоссария пока доступны только для японского. Для других языков проверки качества проще: корейский, русский и упрощённый китайский проверяются по системе письма; при переводе между языками на латинице отмечаются только строки, полностью совпадающие с оригиналом.

macOS сообщает, что приложение нельзя открыть.

У приложения нет подписи Apple. Откройте «Системные настройки» → «Конфиденциальность и безопасность» и разрешите его запуск.

Windows показывает предупреждение SmartScreen.

У приложения нет цифровой подписи кода. Скачивайте его только с официальной страницы GitHub Releases, затем выберите «Подробнее» → «Выполнить в любом случае».

Можно ли переводить моды Steam Workshop напрямую?

Да, но обновление из Workshop может перезаписать ваши изменения. Инструмент сохраняет резервные копии; для важных работ храните отдельную копию перевода.

Как сообщить об ошибке?

Создайте issue на GitHub. По возможности приложите диагностический ZIP из раздела «Настройки» → «Собрать диагностические журналы» и опишите шаги воспроизведения. ZIP не содержит ваших переводов или ключей API.
